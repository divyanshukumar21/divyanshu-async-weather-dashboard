# Divyanshu Kumar - Asynchronous JavaScript & RESTful APIs

## Project
Real-Time Weather Dashboard using public REST APIs.

## Features
- Fetch API
- async/await
- JSON parsing
- Nested JSON data processing
- Error handling
- Search weather by city name
- Dynamic DOM rendering
- Responsive design

## APIs
The project uses Open-Meteo public geocoding and weather APIs. No API key is required.
