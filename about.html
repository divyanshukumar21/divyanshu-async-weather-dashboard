About This Project

A practical project for learning asynchronous JavaScript and API communication.

Fetch API

The application sends HTTP requests using the modern browser Fetch API.

async/await

Asynchronous operations are written with readable async and await syntax.

JSON Processing

API responses are parsed as JSON and nested properties are used to update the interface.

Error Handling

Network and invalid-city errors are caught and shown clearly to the user.
